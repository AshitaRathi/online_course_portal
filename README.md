# 🎓 Online Course Portal

A simple Django-based web application to manage and display online courses. This project is aimed at demonstrating basic functionalities of a course management portal using Django.

---

## 🛠 Tech Stack

- **Backend**: Django (Python)
- **Database**: SQLite
- **Frontend**: HTML, CSS (Django Templates)
- **Static & Media Files**: Managed via Django
